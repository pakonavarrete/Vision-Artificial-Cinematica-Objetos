# Vision-Artificial-Cinematica-Objetos
Implementación de un pipeline de Visión Artificial Clásica para el seguimiento de múltiples objetos (3), cálculo de cinemática (posición, velocidad, aceleración) y conversión de unidades píxel-centímetro en MATLAB.
La practica fue propuesta por el profesor Erick Huitron de la escuela UPIITA-IPN dentro de la materia vision artificial, consiste en mediante el uso del pipeline de vision artificial se adquiera el centroide de 3 objetos de colores distintos y con eso obtener su posición, velocidad y aceleración ocupando metodos matematicos de aproximaciones.
